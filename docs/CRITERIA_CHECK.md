# Проверка готовности проекта

| Раздел | Реализация |
|---|---|
| Польза для студента | Контроль дедлайнов, план на неделю, проверка репозитория GitHub и поиск аудиторий AITU |
| Работа с LLM и MCP | `ArtexAgent` на базе Google GenAI SDK + 8 инструментов FastMCP |
| Интеграции | Прямые запросы к GitHub REST API (`znaukitai/CampusPulseAI_BadPiggies`) и локальный индекс карты AITU |
| Интерфейс | Минималистичный чат, светлая и тёмная тема, быстрые карточки сценариев, встроенная карта |
| Тестирование | Набор unit-тестов (`pytest`) для логики дедлайнов, сериализации агента, цикла рассуждений и MCP-инструментов |
