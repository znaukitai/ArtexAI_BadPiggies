# Сценарий демонстрации CampusPulse

## План выступления (3 минуты)

| Время | Действие | Описание |
|---|---|---|
| 00:00–00:30 | Обзор интерфейса | Показать главный экран чата, переключение тёмной/светлой темы и список дедлайнов в сайдбаре. |
| 00:30–01:10 | Сценарий 1: Дедлайны | Нажать «Что горит на этой неделе?». Агент проверяет дату в `Asia/Almaty` и выделяет главную задачу. |
| 01:10–01:50 | Сценарий 2: GitHub | Нажать «Проверить GitHub-репозиторий». Агент обращается к GitHub API и проверяет репозиторий `znaukitai/CampusPulseAI_BadPiggies`. |
| 01:50–02:30 | Сценарий 3: План недели | Нажать «План учёбы на неделю». Показать распределение нагрузки по дням. |
| 02:30–03:00 | Сценарий 4: Карта кампуса | Найти коворкинг или кабинет `C1.2.223` и открыть интерактивную карту AITU. |
