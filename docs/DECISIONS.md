# Архитектурные решения

| Решение | Обоснование |
|---|---|
| Единый интерфейс на Streamlit | Быстрый запуск Python-бэкенда и UI в одном процессе |
| Контракт `AgentResponse` | Единая структура данных между агентом, MCP-инструментами и интерфейсом |
| In-memory MCP мост | Вызов инструментов напрямую в процессе без накладных расходов на stdio-подпроцессы |
| Встроенный оркестратор MCP | Позволяет выполнять реальные вызовы инструментов (GitHub, дедлайны, карта) даже при отсутствии ключа Gemini API |
| Локальный индекс карты + веб-схема | Мгновенный поиск кабинетов офлайн и наглядный план этажей в интерфейсе |
| Защита GitHub-запросов | Проверка домена `github.com`, запрет редиректов и таймауты |
